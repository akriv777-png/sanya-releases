# Саня — сборки для SideStore

Публичный репозиторий только с установочными файлами приложения «Саня».
Исходный код здесь не хранится.

## Как поставить

1. В SideStore открой Sources → «+» и вставь ссылку на источник:

   https://raw.githubusercontent.com/akriv777-png/sanya-releases/main/apps.json

2. Либо открой на iPhone эту ссылку:

   sidestore://source?url=https://raw.githubusercontent.com/akriv777-png/sanya-releases/main/apps.json

3. Дальше обновления можно ставить из SideStore (и, после первой сборки с встроенным обновлением, из самого приложения).

Релизы: https://github.com/akriv777-png/sanya-releases/releases
